# CAN 통신 명세

STM32는 센서 상태 프레임을 CAN으로 수신하고, 판단 결과로 제동 요청 프레임을 CAN으로 송신합니다. 센서 인터페이스 노드는 센서값을 읽어 CAN으로 발행해야 하며, RC카 측 수신 노드는 제동 요청을 지원해야 합니다. 두 노드 구현/지원 여부와 모델은 확인되지 않았습니다. CAN ID/속도/스케일은 승인된 명세 전까지 미정이며 실제 구동 장치에 임의 프레임을 보내지 않습니다.

## 먼저 구분할 것

- **센서 인터페이스 노드:** 가변저항/버튼을 ADC/GPIO로 읽어 센서 상태 프레임을 발행합니다. 이 노드가 없으면 일반 아날로그/접점 센서는 STM32에 CAN 데이터를 보낼 수 없습니다.
- **STM32 주 제어기 및 CAN/FDCAN 주변장치:** CAN 센서 프레임을 수신하고 유효성/변화율/제동 우선 로직을 실행한 뒤 제동 요청 프레임을 송신합니다. MCU 모델에 따라 주변장치 종류와 HAL이 다릅니다.
- **CAN 트랜시버:** MCU의 TX/RX 논리 신호를 CANH/CANL 물리 버스 신호로 변환합니다. 트랜시버만으로 CAN 통신이 완성되지는 않습니다.
- **RC카 측 CAN 수신 노드:** STM32가 보낸 요청을 받을 제어기와 지원 메시지 명세가 있어야 합니다. RC카의 기존 수신기/속도 제어기가 CAN을 지원하는지 확인해야 합니다.

## 컨트롤러와 트랜시버 수량

CAN 컨트롤러는 프레임을 생성/해석하고, 트랜시버는 컨트롤러 논리 신호를 CANH/CANL 물리 신호로 변환합니다. 컨트롤러는 MCU/ESC에 내장될 수 있으므로 반드시 별도 칩을 사야 하는 것은 아닙니다. 반면 각 버스 노드에는 트랜시버가 필요하지만 보드/모듈에 이미 통합된 경우 외부 모듈은 추가하지 않습니다.

현재 의도한 구성은 센서 노드 → STM32 → RC카 수신 노드의 3개 노드입니다. STM32F407 MCU에는 bxCAN 컨트롤러가 내장되어 있으므로 STM32 쪽은 외부 컨트롤러 칩이 아니라 물리 트랜시버가 필요한 구성입니다. 외부 ADuM20 계열 모듈 2개는 센서 노드와 STM32에 사용할 수 있으나, 이때 RC카 수신 노드는 CAN 트랜시버를 내장해야 합니다. RC카 수신기에 트랜시버가 내장되지 않았다면 외부 트랜시버가 하나 더 필요합니다. 또한 센서 노드에는 가변저항/버튼을 읽을 ADC/GPIO와 CAN 컨트롤러를 가진 MCU가 필요합니다. ADuM20 판매명 모듈이 실제 CAN 트랜시버를 포함하는지는 정확한 부품번호/데이터시트로 확인하기 전까지 미확정입니다.

CAN으로 제동 요청을 보낸다는 것은 제어 메시지를 전달한다는 뜻이지, CAN 버스 자체가 모터 전류를 끊거나 기계적으로 제동한다는 뜻은 아닙니다. 실제 동작에는 요청을 해석하는 수신 제어기와 검증된 제동/출력 회로가 필요합니다. RC카의 해당 경로가 확인되기 전에는 제동 프레임이나 전류 차단 회로를 임의로 정의하지 않습니다.

## 메시지 카탈로그

| 메시지 | 방향 | 목적 | CAN ID | 주기/DLC/필드 |
|---|---|---|---|---|
| `SENSOR_STATUS` | 센서 인터페이스 노드 → STM32 | 가속 위치, 버튼 상태, 순번/시간, 데이터 유효성 전달 | 미정 | 미정 |
| `BRAKE_REQUEST` | STM32 → RC카 수신 노드 | 제동 우선 요청 및 요청 사유 전달 | 미정 | 미정 |
| `RC_STATUS` (선택) | RC카 수신 노드 → STM32 | 요청 수신 확인/상태 전달 | 필요 여부/값 미정 | 미정 |

## 설정 기록

| 항목 | 확인값 |
|---|---|
| STM32 MCU 및 CAN 주변장치 종류 | 미정 |
| CAN 센서 송신 노드 MCU/내장 CAN 컨트롤러 | 미정; 별도 센서 인터페이스 노드 필요 |
| 외부 CAN 트랜시버 모듈 수량 | 2개; 모듈의 실제 CAN 트랜시버 포함 여부 확인 필요 |
| 센서 상태 프레임 수신 노드 | STM32 주 제어기 |
| 제동 요청 송신 노드 | STM32 주 제어기 |

| CAN 트랜시버 모델 및 논리 전압 | 미정 |
| 버스 비트레이트 | 미정 |
| 프레임 형식 (표준/확장) | 미정 |
| CAN ID 및 송수신 노드 | 미정 |
| DLC 및 데이터 필드/단위/바이트 순서 | 미정 |
| 송신 주기와 타임아웃 | 미정 |
| 카운터, 체크섬, 응답 프레임 | 미정 |
