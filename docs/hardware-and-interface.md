# 하드웨어 및 인터페이스 기록

이 문서는 확인한 부품/전기 인터페이스만 기록합니다. 미측정 수치와 미확인 핀은 추정하지 않습니다. 상세 노드 연결은 [회로 설계 기록](circuit-design.md), 메시지 필드는 [CAN ICD](can-protocol.md)를 사용합니다.

## 핀/신호 인터페이스

| 신호 ID | 출발 핀/노드 | 도착 핀/노드 | 방향/전기 형식 | 범위/단위 | 검증 근거 |
|---|---|---|---|---|---|
| IF-SEN-01 | Potentiometer ends/wiper | 센서 노드 supply/ADC | 아날로그 | 미정 | 센서/ADC 데이터시트 및 계측 |
| IF-SEN-02 | Button contact | 센서 노드 GPIO | 디지털, pull-up/down TBD | 미정 | 스위치 사양 및 입력 회로 검토 |
| IF-CAN-01 | 센서 노드 CAN controller | 센서 노드 transceiver | TXD/RXD logic | 미정 | 노드/트랜시버 데이터시트 |
| IF-CAN-02 | STM32 CAN/FDCAN | STM32 transceiver | TXD/RXD logic | 미정 | 정확한 MCU/보드 핀맵 |
| IF-CAN-03 | CAN transceivers | 각 노드 CANH/CANL | CAN physical bus | 미정 | 물리 계층/토폴로지 검토 |
| IF-RC-01 | RC카 CAN receiver | RC카 motor/brake controller | CAN / actuator | 미정 | 제조사 인터페이스 근거 필요 |

## 네트워크 구성

| 항목 | 값 | 상태/근거 |
|---|---|---|
| 노드 목록/역할 | 센서 노드 → STM32 → RC카 수신 노드 | 논리상 3개 노드; 센서/RC카 CAN 기능 확인 필요 |
| CAN 트랜시버 수량 | 외부 모듈 2개 | 충분 여부는 센서 노드 또는 RC카 노드의 트랜시버 내장 여부에 따름 |
| 단일/분리 CAN 버스 | 미정 | 호환성/MCU 채널 확인 필요 |
| CAN 속도 및 프레임 형식 | 미정 | 모든 연결 노드와 합의 필요 |
| 종단 위치/저항/분기 | 미정 | 선택한 물리 계층 사양으로 설계 |
| 오류/통신 단절 시 정책 | 미정 | 안전 검토 및 승인 필요 |
